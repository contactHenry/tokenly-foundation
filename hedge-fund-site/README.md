# Vesperline Capital — hedge fund website

- `relume-build-sheet.md` — the build sheet for Relume: style guide (one font, one palette), sitemap, a prompt for Relume's AI site builder, and every page broken into Relume sections with final copy and image direction.
- `index.html` — homepage preview of the corporate direction. Open it directly in a browser. Images are rendered stand-ins; real photography is placed in Relume.
- `site.html` — the same page without the document wrapper (used for the hosted preview).

Vesperline Capital is a placeholder name. All names, people, figures and terms are illustrative.
