# Vesperline Capital — hedge fund website (design preview)

A standalone, editorial multi-page website for a fictional hedge fund. It does not touch the Tokenly app.

- `index.html` — open directly in a browser. No build step.
- `site.html` — the same page without the document wrapper (used for the hosted preview).

Pages (hash routes): `#home`, `#firm`, `#strategies`, `#approach`, `#insights`, `#letter-q3-2026`, `#careers`, `#investors`, `#contact`, `#disclosures`.

All names, people, figures and terms are illustrative placeholders. The contact form is not connected to an inbox.
